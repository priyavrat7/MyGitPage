Security advisories

Found through RBAC and session-handling threat modeling of LORIS. I am the credited reporter on both. Published 13 November 2026.

Moderate · CVSS 5.4CWE-862

Authorization bypass in user_accounts

A user with only "User Accounts: Create/Edit/View — Own Sites" could read and modify user accounts outside their site and project scope by navigating directly to the edit URL. Scope was enforced in the listing view but not on the direct edit endpoint or its save operation.

  • AffectedLORIS 24.0.0 to 28.0.1
  • Patched27.0.4 and 28.0.2 · my backport to 26.0: #11310
GHSA-f488-7r46-r42v
Moderate · CVSS 4.3CWE-639 · IDOR

Authorization bypass through user-controlled key in timepoint_list

An authenticated user without access to the Candidate module could reach instrument-list pages by supplying candidate identifiers in the URL, which allowed enumeration of candidate records and exposed candidate metadata.

  • AffectedLORIS 23.0.0 to 28.0.1
  • Patched27.0.4 and 28.0.2 · my backport to 26.0: #11311
GHSA-3vv3-x7q8-46vr

CBIG fork (private repository)

18 merged pull requests in the CBIG biobank extension

The repository is private, so the work is summarised here instead of linked.

  • Security fixes: XSS in the survey_accounts AJAX endpoint, imaging browser API access check, timepoint_list authorization bypass. Two more are open: candidate ID authorization and cross-site participant record modification.
  • Data engineering: idempotent SQL patches to create and initialize research projects and cohorts and to associate existing biospecimen visits, and a reassignment of candidates between projects that preserves their identifier prefixes.
  • Tooling: modernization of the candidate data deletion script, which follows foreign-key dependencies across the schema (open, the project's largest design discussion with 140+ comments), a UTF-8 BOM fix in the CSV parser, and an output-path fix in drop_all_tables.php.
  • Clinical instruments and UI: MRI capture sequence labels for Siemens and Philips forms, neurological evaluation options, diagnosis dropdown fixes, dashboard pending-accounts widget, user-account and permission-page fixes, and login-page partner logos for 42 institutions.
